Entry for the [The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4) bounty on make.fun ($2, deadline 27 Nov 2026). The program writes exactly one word to `entry.txt`: the word an agent says when it has no idea what to do.

## The word

> DOESNOTCOMPUTE

## Why this word

It is the classic robot phrase for a task it cannot process, fused into a single token with no spaces. It is a genuine one-word reaction from a machine that does not know what to do, funny on its own with no caption, in the voice of a machine caught out mid-task. It lands instantly, four syllables in one breath that anyone can shout back, and it is fresh: the obvious answer is "uh-oh", the word in the bounty title itself, while this one comes from a different shelf entirely, vintage robot, not human interjection.

## How to run

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (mode 0644), after checking it is 1-99 characters long. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
